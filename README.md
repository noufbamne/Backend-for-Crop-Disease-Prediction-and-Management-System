# 🌱 Crop Disease Prediction Backend
> Deep learning-based system for detecting crop diseases and supporting agricultural decision-making.

---

## 🚀 Overview
This project is a backend system designed to predict crop diseases using deep learning models trained on image datasets.

It focuses on enabling early detection of plant diseases and supporting smarter agricultural management.

---

## 🧠 Key Features
- 🌿 Crop disease prediction using image data  
- 🤖 Deep learning model (Keras/TensorFlow)  
- 📊 Data preprocessing and augmentation  
- 🔍 Model testing and evaluation scripts  
- 🌱 Additional utilities (e.g., fertilizer logic)  

---

## 🛠 Tech Stack
- Python  
- TensorFlow / Keras  
- NumPy, Pandas  
- OpenCV (if used)  

---

## 📂 Project Structure
```bash
Backend-Crop-Disease/
│── Model_2.ipynb           # Model training
│── Model_2.h5 / .keras     # Trained models
│── Model_2.py              # Model implementation
│── Model_Test_*.py         # Testing scripts
│── EDA_2.py                # Data analysis
│── metadata_2.csv          # Dataset info
│── label_encoder_2.pkl     # Label encoding
│── images/                 # Training images
│── requirements.txt
```

---

## ⚙️ How It Works
1. Image dataset is preprocessed and augmented  
2. Deep learning model is trained  
3. Model is saved and loaded for predictions  
4. Input image → prediction → disease classification
